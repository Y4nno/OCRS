# Registration Service - OCRS

This microservice is a part of the **Online Course Registration System (OCRS)** of LionHeart. It handles the student course registrations, including creation, updating, deletion, and querying of registration records.

## Tech Stack

- **Frontend**: React
- **Backend**: Go (Golang)
- **Database**: PostgreSQL
- **Graphql API**: gqlgen
- **Migrations**: [golang-migrate](https://github.com/golang-migrate/migrate)
